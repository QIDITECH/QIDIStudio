# QIDI Studio MCP v1.5.0 Changelog

Release date: 2026-08-08
Target: QIDI Studio 2.7.2.10
MCP tool count: 106

## Overview

v1.5.0 begins the slicer-automation phase with native adaptive layer-height control. The first milestone adds explicit-object inspection, read-only preview, undoable application, smoothing, and reset operations without depending on the visible variable-layer-height gizmo.

## Added

- `get_layer_height_profile`
- `preview_adaptive_layer_height`
- `apply_adaptive_layer_height`
- `smooth_layer_height_profile`
- `reset_layer_height_profile`

## Design

- Profiles are generated by QIDI Studio's native adaptive layer-height engine.
- Tools target an explicit `object_id`; the selected object and open gizmo do not control the result.
- `quality_factor=0.0` favors speed and `quality_factor=1.0` favors surface quality.
- Inspection distinguishes a stored object profile from the effective profile derived from active uniform settings.
- Smoothing exposes the same radius range and keep-min behavior as QIDI Studio's native UI.

## Safety

- Preview never mutates the project.
- Apply, smooth, and reset refuse to run during slicing or another active QIDI Studio job.
- Each mutation creates an undo snapshot and schedules native background reslicing.
- Automatic camera diagnosis and automatic print cancellation remain out of scope.

## Validation

- Static source audit: 106 unique tool definitions and 106 unique dispatch branches, with exact parity.
- Version audit: both `serverInfo.version` and suite capability reporting are `1.5.0`.
- Windows x64 `RelWithDebInfo` build completed successfully in 00:51:42.66.
- Connector refresh exposed all 106 tools and reported suite `1.5.0`.
- Live inspection, read-only preview, apply, native undo, smoothing, and reset all passed.
- The tested project was left at its original uniform 0.20 mm profile; nothing was sliced or printed.
